  • V2 Prime: Four integrated motor drivers can suit X/Y/Z/Titan if actual current ratings fit; Prime bed output contacts J13.1 VFET and J13.2 SW_BED are source-derived. P12 schematic now establishes J17 Hotend A and J19/J20 fan outputs; these conditional circuits require actual heater/sensor/fan and firmware qualification.
Retain or add
  • Identify installed controller and record motor, sensor, heater, bed, fan and supply labels before removal.
  • For Core: four named external stepper drivers matched to measured motor nameplates; rated heater switching peripheral(s) and sensor conditioning where required.
  • Conditional Core PT100 option: MAX31865 SPI RTD converter with ADI MAX31865PMB1 (3.3V Pmod, J2 2-wire jumpers) only after sensor identification and firmware driver support; Smoothieware MAX31865 support is not verified.
  • Independent thermal cutoff and fusing for each heater, retained protective earth and a hardware-safe power disconnect.
  • Conditional Prime P12 heater/fan stages: use J12 XT30 VFET entry, J17 Hotend A, J19/J20 fans only with measured matching loads, branch fuse and independent thermal cutoff; temperature feedback/firmware is a blocking qualification gate.
Conversion and commissioning
  1. Confirm actual board revision and photograph both PCB sides/cable headers before changing wiring.
  2. Measure each motor winding pair and identify each cavity; set current and test one axis at a time.
  3. Read E3D sensor and heater part markings; measure cold sensor resistance and heater resistance. Match firmware curve/amplifier and heater voltage/current before applying heat.
  4. For Prime bed switching, use source-derived P12 J11.1 VFET/J11.2 GND_FET supply-distribution contacts and J13.1 VFET/J13.2 SW_BED output only after bed load rating and fuse checks. J11/J12/J16 are supply distribution, not switched heater outputs.
  5. For a confirmed PT100/PT1000 on Core, verify J36 SPI nets and choose an exact MAX31865 module/logic level plus firmware driver before wiring; otherwise select a sensor-matched thermistor ADC interface.
  6. Keep hotend heater power OPEN until its board output, rail, wiring, fuse, thermal fuse and connector ratings are source-verified.
  7. Identify every fan voltage/current and all six limit/probe contacts; test NO/NC and signal range. Verify plausible ambient temperature, then test one heater with independent cutoff/current monitoring.
  8. MAX31865PMB1 datasheet BOM lists installed R7=400Ω ±0.1% as its PT100 reference resistor; BIAS is internal, not a separate wiring terminal. Verify module revision and resistor population before connecting an RTD.

Ultimaker 2

Research status: wiki-sourced machine dossier; MakeICT lists it operational. Captured 2026-09-23.

Wiki-recorded configuration

MakeICT identifies the unit as an Ultimaker 2. Its wiki page lists 210 × 210 × 200 mm build volume, 1.75 mm filament, 0.4 mm nozzle, heated bed to 100 °C, and table values of 0.125 mm X/Y and 0.02 mm Z resolution. The page says the installed machine was modified with an E3D V6 hotend and geared E3D Titan extruder, and unlike the stock variant uses 1.75 mm filament.

Use and access

The wiki points operators to the space’s shared 3D Printing authorization policy and workflow. It does not contain a machine-specific start sequence in the inspected page. The inventory labels the unit operational.

Connections and pinout

No board revision, connector, motor, heater, thermistor, fan, or power pinout is published on the wiki page.
