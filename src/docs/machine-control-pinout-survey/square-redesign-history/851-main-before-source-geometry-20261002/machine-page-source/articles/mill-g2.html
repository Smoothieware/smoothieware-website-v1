Current installation sequence
  1. Match the actual machine and controller revisions, trace the unpowered harness and verify all signal/reference, power and independent safety boundaries before energising. Follow the current connection IDs rather than the superseded architecture prose.
  2. X motor: integrated Prime phase outputs: Source establishes Prime output net names. Machine lead order and phase pairing are unknown; identify coils with power isolated.
  3. Y motor: integrated Prime phase outputs: Source establishes Prime output net names. Machine lead order and phase pairing are unknown; identify coils with power isolated.
  4. Z motor: integrated Prime phase outputs: Source establishes Prime output net names. Machine lead order and phase pairing are unknown; identify coils with power isolated.
  5. 775 spindle controller: PWM, direction and motor output: Prime J35.6 exports TIM1_CH1 (PWM candidate) and J35.10 GND. Cytron MD10C R3.0 has PWM, DIR, GND, VM, PWR_GND, OUT_A/B; manual Rev3.0 V1.0 Aug 2018 supports sign-magnitude PWM+DIR and 3.3/5V logic. DIR tied to logic GND selects Forward while PWM is high per the manual truth table; bench-check actual spindle rotation and ensure PWM low stops/brakes as expected. Separate motor supply must match measured motor voltage/current and be fused. Do not use guessed red/black wiring.
  6. Dedicated 775 spindle power stage: Do not assume the original 24 V / 4 A adapter is sufficient for controller, axes and spindle together. MD10C source says no overcurrent protection.
  7. X MIN limit input (candidate mapping): Prime source pin schedule: J24-J29 pin2 GND, pin3 input, pin1 selector. This candidate J-to-axis/end assignment is not established by Genmitsu manual; trace each harness and test switch state first.

  10. Y MAX limit input (candidate mapping): Prime source pin schedule: J24-J29 pin2 GND, pin3 input, pin1 selector. This candidate J-to-axis/end assignment is not established by Genmitsu manual; trace each harness and test switch state first.
  11. Z MIN limit input (candidate mapping): Prime source pin schedule: J24-J29 pin2 GND, pin3 input, pin1 selector. This candidate J-to-axis/end assignment is not established by Genmitsu manual; trace each harness and test switch state first.
  12. Z MAX limit input (candidate mapping): Prime source pin schedule: J24-J29 pin2 GND, pin3 input, pin1 selector. This candidate J-to-axis/end assignment is not established by Genmitsu manual; trace each harness and test switch state first.
  13. Prime selected · separate logic and motor supplies: This is the alternative integrated-driver architecture. The same PCB-derived contact labels occur on P121/P12, but driver type, rating and current configuration differ. Use one verified power-entry arrangement; J10 parallels VMOT and is left unused here. Board ground is shared internally; route motor current directly to power distribution, not through logic wiring. Determine actual allowed voltage/current before choosing a supply; no machine-source adapter automatically qualifies.
  14. Included Z height probe · plate and tool clip separately: Documented probe kit; verify this fitted kit is a passive isolated contact. J31.4 is conditioned through comparator U24; establish JP7/JP8 population and safe pull-up/configuration from the exact P12 sheet. Leave J31.1 VMOT and J31.2 selected supply unused for a passive plate. Probe input maximum differs between board guides; no high-voltage capability is claimed.
  15. Optional laser module · controller signal, return and separate power: Manual p.6 says optional laser is not included. Only populate this circuit if fitted. Identify laser driver model, TTL polarity/threshold/current, command connector and independent laser inhibition before choosing the level interface. Do not connect a logic output to laser power. Prime J35.6 is only a proposed PWM resource; verify firmware ownership.
  16. Air pump interface · optional/fitted pump must be identified: Manual pp.19–20 names the air-pump interface but gives no pump model, connector pin map or load rating. Proposed DC pump load on Fan2 only after VFET voltage, startup/stall current, flyback suppression and connector rating are established. J20.1 is cutoff-switched VFET, J20.2 Q22 switched return; verify exact P12 firmware/resource assignment and reuse one VFET supply, not a second source tied to the same rail.
  17. Emergency stop · independent hazardous-energy interruption: Manual pp.19–20 names E-stop interface without contact numbers or safety topology. Trace fitted switch and contactor/drive-inhibit circuit before wiring. Board-only firmware stop cannot assure safe stop. No Prime GPIO is presented as the hazardous-energy cut-off.
  18. Factory offline controller and MPG · protocol is not a GPIO pinout: Manual p.28 warns factory offline port is designed for its controller and must not connect other controllers. Keep factory offline controller/MPG disconnected from Prime until protocol, electrical levels and replacement firmware support are established. J30 debug UART is not an assumed factory pendant adapter.
  19. Resource conflict: spindle PWM C04-001 and optional laser PWM C14-001 both nominate Prime J35.6 TIM1_CH1. These are mutually exclusive alternatives, not two independent outputs. Disconnect the unused load or source and configure a distinct supported PWM output; never wire both loads expecting independent control.

Owner retrofit guide · Genmitsu 3018-PROVer V2 retrofit

The drawing provides individual motor, command, power and peripheral conductors. Select one controller architecture from the target assessment; alternatives must not be wired at the same time. Retain only matching, measured machine harnesses and commission each circuit against its listed gate.

Which Smoothie target fits this machine?
  • SmoothieBox: Enclosure/carrier only; choose and wire the contained Core or Prime below after confirming its exact board and harness.
  • V2 Core: Three external drivers are required. Candidate StepperOnline DM320T provides named PUL/DIR/OPTO and P2 A+/A-/B+/B- terminals; match motor current and verify Core logic interface.
  • V2 Prime: Integrated X/Y/Z stepper outputs are plausible only if selected P11/P12 variant, motor current and power rating match. Output pins are winding phases, never STEP/DIR.
Retain or add
  • One StepperOnline DM320T per Core-controlled axis, with a TI SN74LVC07A six-channel open-drain buffer proposal (three buffers, one per axis (only two of six channels loaded per device)); manual exposes P1 PUL/DIR/OPTO/ENA and P2 +Vdc/GND/A+/A-/B+/B-.
  • Cytron MD10C R3.0 candidate for the brushed 775 spindle; dedicated fused supply after measuring motor current. R3.0 manual supports PWM+DIR sign-magnitude with 3.3/5V logic; fixed DIR logic must be verified before tying.
  • Retain the physical E-stop/safety chain; identify machine switch/probe/laser peripherals before wiring.
Conversion and commissioning
  1. Core power candidate: route the selected, fused and voltage-verified board supply to Core P1 J42.1 (/5VPORTIN) and supply return to J42.2 (GND). Check exact Core revision input range/current and upstream fuse before energizing; do not mistake J42.1 for a 5V output.
  2. Record board/motor/PSU revision and use continuity to identify each 4-wire motor coil pair before connection.
  3. For Core, use SN74LVC07A channels as 3.3V-input open-drain sinks: for each axis use one SN74LVC07A (STEP A1→Y1 pins1→2, DIR A2→Y2 pins3→4); pins5/6,9/8,11/10,13/12 remain unused. Power each pin14 from Core J5.10 3V3, pin7 to one verified J5 return, and fit 100nF directly across each device. DM320T PUL/DIR inputs draw 7–16mA each: two loaded sinks total 14–32mA/device, below TI 100mA package GND-current absolute maximum; verify actual input-current setting and scope pulse timing.
  4. Set motor current from the motor nameplate, fuse every stage, and test one unloaded axis at conservative speed.
  5. Map each individual MIN and MAX switch to its own Prime input only after continuity and NO/NC checks; do not infer connector assignment from socket placement.
  6. Test PWM into MD10C with spindle disconnected first; then test secured spindle at low duty/current. Prove E-stop removes hazardous energy independent of firmware.

What is still missing

The manual and reviewed board establish selected V2 socket counts, not mating-face cavity roles, motor coil continuity, the fitted board subrevision, or which A/B limit socket each production machine occupies. Confirm a replacement drive, spindle power stage and safety circuit before wiring.

Documented evidence · unresolved wiring

Documented: Same SainSmart laser table, 3018-PROVer V2 row: laser cable 12 V / GND / PWM, no extra PSU; V2 manual v1.0 (2022), pp. 4, 16–19, identifies 32-bit/TB67S109 board, 4-wire Y motor, 3-wire Y limit and red/black spindle motor polarity. Unresolved / version scope: The laser cable row is a function sequence, not a drawing of board-facing pin 1. Limit/motor connector contact order and controller PCB revision still need manufacturer drawing or physical silk.

2026-09-26 V2 source update: The manufacturer manual and SainSmart-hosted hands-on review support 52 selected OPEN references in 15 cards. The review’s example board photo is marked GC3D3-V4.3, which does not prove that subrevision on every V2. It reports three occupied limit sockets of six, with each axis’s two switches in parallel; the specific occupied socket and its signal/supply/return order are unknown. The V2 illuminated Z-probe has three board positions, unlike the first-generation two-position probe. X/Y/Z motor sockets are TB67S109 former-controller winding outputs, not STEP/DIR inputs. Spindle red+/black− leads are motor power; EStop has no proved safety rating or contact state; laser and AIR are optional board outputs with no fitted device proved. No SmoothieBox route or dotted guess is selected.
