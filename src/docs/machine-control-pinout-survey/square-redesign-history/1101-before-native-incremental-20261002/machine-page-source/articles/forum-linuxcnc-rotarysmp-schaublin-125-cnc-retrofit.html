Current installation sequence
  1. Match the actual machine and controller revisions, trace the unpowered harness and verify all signal/reference, power and independent safety boundaries before energising. Follow the current connection IDs rather than the superseded architecture prose.
  2. Retained owner-reported spindle circuit: Mesa 7i83 analogout0 → unknown VFD: SmoothieBox exterior contact assignment is a proposed Chapter 18 harness; verify the fitted case and logic level. Owner reports 7i83 analogout0 commands VFD speed. A later post identifies physical VFD Pin 28 as drive enable while discussing analog 0-10V speed command and stop behavior. Pin 28 is an owner-reported terminal label/function only; identify the VFD model and verify all actual connections. M3/M4 failure was reported even while panel buttons functioned.
  3. Owner-reported spindle encoder feedback; Smoothie compatibility blocked: SmoothieBox exterior contact assignment is a proposed Chapter 18 harness; verify the fitted case and logic level. Thread documents Mesa encoder speed feedback, not encoder model, A/B/Z electrical standard or connector schedule. No arbitrary direct encoder connection to SmoothieBox/Prime is proposed.
  4. JMC servo control compatibility decision (not a pin-level connection): SmoothieBox exterior contact assignment is a proposed Chapter 18 harness; verify the fitted case and logic level. Owner post #259199 explicitly says the JMC drives are running in analog mode. Either verify the exact installed drives can be configured for compatible pulse-position commands, or retain a supported closed-loop motion controller/drive architecture. No SmoothieBox-to-analog position loop is proposed.
  5. Pneumatic backgear: valve identity and stopped-spindle interlock required: SmoothieBox exterior contact assignment is a proposed Chapter 18 harness; verify the fitted case and logic level. Owner says gear changes only with spindle stopped, and no gear-position sensor is fitted/reported. Planned 7i84/brake outputs were not confirmed installed. Identify manifold station and coil; add independent spindle-stopped permissive before any actuation.
  6. Preserve existing physical spindle/safety controls until traced and verified: SmoothieBox exterior contact assignment is a proposed Chapter 18 harness; verify the fitted case and logic level. Thread reports damaged spare Mesa 7i84 and planned quick-stop/brake at cited time; current installation unknown. Do not label planned parts as installed. Keep safety and contactor logic independent of Smoothie. The named physical controls and safety functions are retained for tracing; no controller-to-contactor or forward-to-E-stop wire is proposed.
  7. Spindle speed and run · SmoothieBox interface proposal: Owner reports original 0–10V speed mode and VFD Pin28 enable. Identify fitted VFD model, analog range/return, enable circuit and safe stop behavior. Proposed PWM-to-0–10V conversion and isolated run contact are process control only; not a replacement for the retained spindle safety and closed-loop axis control.
