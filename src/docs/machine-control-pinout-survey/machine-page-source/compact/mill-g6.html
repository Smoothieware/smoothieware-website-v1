Genmitsu 3030-PROVer MAX + supplied GRBL 1.1h 32-bit controller board

Connector groups

The Genmitsu manual names board sockets A Axis, Air Pump, Laser, Offline Controller, Y/E/P, Handwheel and USB. Its printed p. 20 (PDF p. 22) identifies spindle motor red positive and black negative conductors; SainSmart lists an optional laser cable in 12V/GND/PWM table order. These five leads are source references, not verified connector cavity numbers. The 3/6/14-pin offline-controller and 8-pin power-box harness functions remain unnumbered OPEN groups.
