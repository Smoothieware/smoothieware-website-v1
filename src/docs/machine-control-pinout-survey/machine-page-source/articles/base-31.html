Interface reading

Signal domains: Motor drive, pen lift or servo, USB/control. Controller family: EBB v2.4.

What is still missing

Motor connector nets are phase outputs, not step/dir; check actual EBB revision, populated headers and mechanism mapping. Verify firmware separately from board v2.4; optional external step/dir headers in the schematic may be unpopulated.

The installed EBB v2.4 has onboard A4988 stepper drivers. JP19/20 duplicate headers are labelled Do Not Insert/unpopulated, and JP13/16/17/18 are motor-winding outputs. EBB board project; cited CC BY 3.0 US licence.

Documented evidence · unresolved wiring

Documented / version scope: Maker EBB board page explains EBB drives two steppers onboard and exposes RC-servo headers; v2.4 is SparkFun-derived and its schematic/board layout are available. v2.4 schematic governs motor-winding output labels, not external step/dir by default. Maker boot configuration assigns B1/RB1 to servo, B0 pause input, B3 engraver output, B4 alternate pen-down output for firmware ≥2.1.4. Maker command reference states SC,2,1 disconnects PIC from internal drivers so step/dir/enable can instead be driven through J5/J4; that is an optional configured mode, not stock EggBot wiring. Retain board/firmware scope. The motor phase/wire colours of a particular EggBot have not been proven.
