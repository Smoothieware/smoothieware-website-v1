2026-09-26 cable-reference update: The base manual V2.0 Jun 2026 (printed p. 20/PDF p. 22) identifies a black three-position Z limit cable and white four-position Z motor cable. The separately offered wireless Z-probe tool setter lists a dedicated three-position XH2.54 cable compatible with this model, but not a fitted accessory or a proven cavity-role order.
