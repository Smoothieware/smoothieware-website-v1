Documented evidence · unresolved wiring

Documented / version scope: Author configuration.ino, lines 535–590 conflicts internally. Commented Connection Directions assigns Motor A physical IN1–IN4 to Arduino D2/D3/D4/D5 and Motor B to D6/D7/D8/D9, while executable constructors assign motorA(8, 6,8,7,9) and motorB(8, 2,4,3,5) (middle values reordered for AccelStepper). Do not publish a settled physical A/B mapping. D9 also conflicts with the usual pen servo noted above. The two four-signal sets have disputed motor association; 28BYJ-48 winding harness polarity/voltage is not proven here. The earlier asserted A=D6–D9/B=D2–D5 is an executable-code interpretation only.
