Updated source scope

The HSBNE machine wiki links the HILDI project. Its LinuxCNC 2.8 configuration, generated 2021-10-20, selects a Mesa 7i76E. The official Mesa manual supplies numbered TB2–TB6 board contact functions; the dated HILDI HAL file maps X/Y/Z step generation, selected home/probe/MPG inputs, spindle enable, coolant flood and status lights.

This source does not establish that the 2021 configuration or board revision is currently installed, the machine harness landing points, external signal levels/polarity, or a compatible SmoothieBox route.
