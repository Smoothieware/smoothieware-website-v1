Smoothieboard/OpenPnP dual-head pick-and-place prototype

Evidence depth: exact-project identity and selected build components are supported by the Appropedia catalogue and John Deglavina’s Hackaday project log. The separate OpenPnP-OpenBuilds source is an ancestor design, not proof of this prototype’s installed wiring.

Direct-prototype sources and facts

The Appropedia row names John Deglavina, calls this a working Smoothieboard/OpenPnP dual-head pick-and-place prototype, and says it is built on the OpenPnP-OpenBuilds model. The exact-project Hackaday log says it draws ideas from multiple machines and used OpenPnP-OpenBuilds as a starting point. It names a Smoothieboard 5X (initially acquired as 4X, then upgraded with added components), OpenBuilds frame parts, automatic feeders, and a RobotDigg dual head with linear rails. The log does not publish the installed connector cavity schedule.

Electrical connections and source boundary

The exact-project logs mention cameras, feeders, solenoids, a vacuum pump, and other build details, but do not establish their fitted connector cavities or Smoothieboard contacts. The OpenPnP-OpenBuilds instructions/configuration and diagram document a separate community build and its MCU software assignments; these are not the prototype’s physical contacts. Keep all such routes OPEN until an exact-project connector/harness source identifies both endpoints. No DB25 is evidenced.

0816 source-model cable reference

The exact-project BOM names the 0816 feeder. Its feeder-PCB v3 documentation lists +5 V, GND, servo PWM and feedback, and records feedback as added in v2. The source design uses one PCB per feeder. These four functions describe one reference cable, with fitted revision, feeder count, contact order, mating view, electrical contract and host pins unknown. The native Arduino Mega shield is a separate controller reference. No fan-out, shared return or SmoothieBox route is inferred.
