RichAuto’s official A18 product page identifies a four-axis system with an 8-input/8-output interface board and a 50-core cable; its parameter table separately says “Controlled Axis Number 3 axis.” The common A1X manual has generic interface-board output/input schedules, while its A18-specific §8.2 table provides the A18 input functions. Those are controller-side reference marks only: the SoMakeIt page does not identify the installed terminal board, 50-core conductor mapping, drivers, or cabinet handoff.

The full listed schedules are kept separate below. X01–X08 differ between generic A1X §3.2 and A18-specific §8.2: generic X04 is tool setting and X08 pedal switch; A18 §8.2 assigns X04 A-axis zero and X08 E-stop. The A18 output schedule is not reconstructed from generic terminal references. The generic A1X fourth-axis output group is labelled C_AXIS while the A18 input chapter uses A; the wiring manual and product page do not map the particular machine harness between those marks.

Every listed position is OPEN to SmoothieBox. The A18 pulse/direction marks are controller outputs; the driver inputs and any safe controller changeover are undocumented. No dotted route is justified. The SoMakeIt rotary group has no numbered contacts, mist coolant remains pneumatic, and no DB25 is established.

StyleCNC STM6090

Research status: wiki-sourced machine dossier; exact model absent from the frozen atlas and exact-name repository search. Captured 2026-09-23.

Identity and configuration

SoMakeIt identifies a four-axis (XYZ plus rotary) StyleCNC STM6090 with a 600 × 900 mm bed, 600 × 750 × 150 mm effective work volume, and RichAuto A18 controller. The space notes modifications for coolant and dust collection. Its controller is operated from the machine; the wiki reports Vectric VCarve Makerspace Edition on a nearby PC for CAM.

Wiki-recorded workflow

  1. Create a CAD model and generate G-code with CAM.
  2. The wiki says the default controller workflow has the spindle on and feeds/speeds selected through a menu before running a program; its intermediate page covers configuring these from G-code.
  3. The wiki describes a mist-coolant setup for aluminium and similar materials. For wood, it instructs users to raise the mist head and disconnect the air supply. Its page states a 5% coolant-oil / 95% distilled-water mix.
  4. Four-axis use is not fully described: the wiki says VCarve substitutes rotary moves for X or Y and therefore does not provide true simultaneous four-axis paths; manual moves or software with the needed feature are required.
