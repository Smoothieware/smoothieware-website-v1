2026-09-26 original-project source update

The project electronics drawing and Electronics Diagram table identify 23 peripheral cards without contact positions. The project-hosted SKR 1.4 Turbo pin map adds seven former-board connector cards and 27 OPEN printed marks: X, Y, Z Y-side, Z E0-side, E0 and E1 motor outputs each show 2B/2A/1A/1B; Z-STOP shows 5V/GND/1.27. The Z labels locate two board sockets, not two established machine Z axes or proof both are occupied. Motor-output marks are post-driver winding outputs, not SmoothieBox STEP/DIR inputs. None of these 30 cards proves a fitted PixiePlacer harness cavity or direct conductor. The table repeats 2.05 for Down LED and vacuum pump; project OpenPnP settings use a pump command there but do not resolve the physical LED or wiring. No SmoothieBox wire or dotted function guess follows.
