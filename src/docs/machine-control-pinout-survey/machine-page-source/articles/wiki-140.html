EleksMill CNC router — CoMakingSpace

Wiki evidence status: named small CNC router documented as a working learning machine. The exact EleksMill generation and controller hardware are not specified.

Machine details

The CoMakingSpace wiki describes an EleksMill brought into the space as a small machine for learning CNC routing. The page lists a 130 × 90 × 40 mm working range, notes that available Z clearance depends on endmill length, and says the machine has no endstops. Foam is the only material currently listed for use; 1/8-inch end mills are named.

Workflow

The wiki says to create a toolpath in CAD/CAM software such as Fusion 360, choose a GRBL postprocessor, secure the material, home/jog and set work coordinates, then send G-code. It compares the workflow to the larger WorkBee router. The source page notes that it is a CNC-router introduction machine; it does not provide a tested speed/feed table.

Pinouts and visual evidence

No controller make/model, axis wiring, motor pinout, limit-switch map, or electrical diagram is provided. The note that it has no endstops is a machine-level limitation, not a connector map. The wiki page includes a photograph captioned as routing styrofoam; it does not expose a wiring or dimensioned mechanical drawing in the captured page text.
