Documented evidence · unresolved wiring

Documented / version scope: AxiDraw CLI reference states standard PWM pen servo = EBB B1, lowest 3-pin set; optional narrow-band brushless pen servo = B2, third position up. Stronger manufacturer AxiDraw Guide v5.50, §12.7 Wiring gives AxiDraw V3 wiring: left motor goes to Motor 2, right motor to Motor 1; motor lead order yellow/red/green/gray from top to bottom; pen servo B1, black wire toward board edge. Maker forum technical reply states B-series 3-pin orientation: edge = GND, middle = +5 V, inner = signal. The PDF is the strongest contact/harness source, but scope explicitly to V3, not every AxiDraw model or EBB revision. Existing code excerpt does not itself prove physical wire order.
