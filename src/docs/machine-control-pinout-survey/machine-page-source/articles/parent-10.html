2026-09-26 Jackpot V1 output-source update

The published Jackpot V1 setup and JP1 LowRider configuration assign X, Y0, Z0, Y1(A), Z1(B). The official V1 board photo shows four visible contacts per socket. Atlas ordinals follow the photo only; the sources do not identify contact phase, machine-end cavity or cable continuity. The sixth C socket is not assigned in this configuration. These 20 contacts remain OPEN former-controller winding outputs, not STEP/DIR inputs or approved SmoothieBox conductors.
