Documented evidence · unresolved wiring

Documented: V1E Jackpot controller manual “Wiring” lists MPCNC X0,Y0,Z,X1(A),Y1(B) and probe gpio.36; switch inputs active low. Jackpot2 manual repeats machine map and states standard NC endstop wiring. Unresolved / version scope: The Jackpot2 page is later-board corroboration, not proof a Primo has Jackpot2. The V1E Jackpot manual is the board-level source for this pairing. No motor coil contact/color order established from these pages.

2026-09-26 Jackpot V1 output-source update

The published Jackpot V1 setup and JP1 MPCNC configuration assign X0, Y0, Z, X1(A), Y1(B). The official V1 board photo shows four visible contacts per socket. Atlas ordinals follow the photo only; the sources do not identify contact phase, machine-end cavity or cable continuity. The sixth C socket is not assigned in this configuration. These 20 contacts remain OPEN former-controller winding outputs, not STEP/DIR inputs or approved SmoothieBox conductors.
