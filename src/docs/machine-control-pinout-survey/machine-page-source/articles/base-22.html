Documented evidence · unresolved wiring

Documented / version scope: The Makerbase hardware wiki and PIN PDF (printed V2.1_002) plus SCH PDF (printed V2.0_001) are revision-conflicted board references, not a verified V2.1_003 contact map. The maker drawing shows the one-page PIN drawing: top edge motor connectors X/Y1/Y2/Z each depict left-to-right 2B 2A 1A 1B; separate 12/24 V +/− supply and laser TTL marked IO32 GND 12/24V; right edge I2C 3V3 GND IO0 IO4, Probe 5V GND IO22, Z− 5V GND IO34, Y− 5V GND IO35, X− 5V GND IO36; left edge labels 12/24 V + GND, beeper S+12/24 V, spindle IO32+12/24 V, switch, power. The source folder says V2.1_003, but the PIN title block says Rev V2.1_002, dated 2021-11-20, and the SCH title block says Rev V2.0_001, dated 2021-10-15. Neither file verifies an installed V2.1_003 connector or electrical contract; keep that V2.1_003 installation OPEN; the separate V2.1_001 board reference is inventoried in the current register. The motor four-contact labels are driver winding outputs, not step/dir logic. Do not transfer them to another board revision or machine without a matching installed PCB and cable audit.

2026-09-26 V2.1_001 source update: The revision-specific PIN sheet and matching schematic support 77 selected OPEN reference positions across 20 cards. Four motor sockets are former-controller winding outputs; optional E/S/D/G footprints do not prove fitted external drivers. The remaining cards cover limits, probe, laser, auxiliary output, spindle, beeper, I2C, switch, MCU reset and EXP1/EXP2. The V2.0 wiring manual is function context only; its board geometry is not imported. The power-input jack, USB/SD and driver-carrier internals are outside this contact count. Reset is not a safety-rated emergency stop. No installed driver, motor, display, laser, wiring, electrical interface or SmoothieBox route is established.
