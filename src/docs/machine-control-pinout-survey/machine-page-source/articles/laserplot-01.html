Contact assignments

The Mini Gerbil 2 V1.1A J3 photo shows LO, 5V, GND, 24V in drawing order. Manufacturer Type 1 and Type 2 guides assign J6 to the Y motor; J7 is the X motor output only on a non-ribbon build, where J5 carries limit switches. A ribbon build uses J4 for X motor and limits. J1 is the former controller PWM output. These are source references, not a verified fitted K40 harness or SmoothieBox route.

Documented evidence · unresolved wiring

Documented: MG2 installation Step 8 documents J3 LO/5V/Gnd/24V keyed 4-wire power/laser-on harness; selected K40s have 6-position plug with only four wires requiring explicit reseating. Type 1 guide names J6 as Y motor and non-ribbon J7 as X motor; a ribbon build uses J4 for X and limits. The Type 2 guide confirms the J6/Y and J7/X labels and separately shows J5 limits and J1 PWM. Its motor contact order is a source drawing reference, not an independently verified V1.1A mating view. Unresolved / version scope: MG2 V1.1A retrofit, not factory K40 or MG3. J3 labels are vendor silk, while exact physical viewed order must follow keyed header photo. K40 wire colors vary per vendor.
