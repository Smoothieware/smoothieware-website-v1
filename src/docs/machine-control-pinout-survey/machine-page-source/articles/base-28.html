Contact assignments

The 22.2 PDF calls itself a later model revision, while Avid’s index calls 22.2 an electronics revision. Both name the same cable families; the contact table and nearby prose disagree about the spindle analog pair. The current source-scoped cards enumerate control-cable positions 1–14 and CRP850-00E terminals 1–42. Option-dependent contacts can be populated but disconnected, and no installed SmoothieBox route is established.

Interface reading

Signal domains: Motion control or motor phases, limits/probe, spindle and safety where fitted. Controller family: Avid PnP.

What is still missing

Do not transfer 17.4 pin claims without reading the 22.2 table and installed controller label; confirm spindle/plasma option.

Documented evidence · unresolved wiring

Documented: Avid 22.2 schematic, official revision page; cited 22.2 manual PDF is Plug_and_Play_CNC_Controller_Technical_Manual_22.2_v2025Q1.pdf. 42-terminal CRP850 is documented for 22.2, but a separate PDF explicitly labelled 17.4 also shows 42 terminals; its analog output is 37/38 and cannot be conflated with the 36-terminal 17.4 HTML layout at 31/32. External 14-contact spindle cable uses 7 relay FWD, 8 DCM, 9 analog voltage, 10 analog common, 11 optional 10 V reference per connector table; prose mentioning 8/9 differs from table. Motor DB9/XLR are phase outputs, not V2 step/dir inputs. Unresolved: check PDF exact revision/contact face and reconcile cable prose/table before stickers.
