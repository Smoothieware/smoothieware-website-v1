Research capture: 2026-09-23. Status: wiki-grounded draft; integration and whole-repository deduplication pending.

Identity, use and deduplication

FabLab Winti manual lathe. The machine directory labels the linked Drehbank page “Schaublin 102-VM”; the image also shows the model on the bed. This is distinct from the atlas Tormach/Sherline/Taig lathes. It is manual maker machinery, not a newly identified CNC retrofit.

Wiki-supported machine facts

Wiki specifies 16 × 16 mm tools and requires mechanical training and induction. It reports a tailstock center-height alignment problem at this installation; that is a local maintenance condition, not a universal 102-VM characteristic. Community machine page.

Control, setup and use

The source advises finishing precision bores by boring rather than relying on drilling while the stated alignment problem remains. CNC homing, G-code and motion-controller setup are not applicable to the documented manual configuration. Motor starter ratings and terminals remain unknown. Community machine page.
