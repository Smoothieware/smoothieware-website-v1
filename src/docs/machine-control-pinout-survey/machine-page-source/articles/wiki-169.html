Markforged Mark 2 3D printer

Identity

Artisans Asylum's wiki identifies a Markforged Mark 2, serial unknown, in its Digifab shop. A nearby version of the wiki's prose calls it “M2”; this dossier retains the structured model field “Mark 2.”

Wiki evidence

  • Artisans Asylum Mark 2 page: model, mechanical arrangement and dry-box use for structural filament.
  • Artisans Asylum FDM printer category: shared operator training and safety notes.

Machine details

The wiki describes a 300 × 150 mm stage, one vertical screw jack, ball-bearing X/Y rails with an H-pattern belt and dual-material extrusion. Structural filament is held in a dry box; the page says the extruder has no proximity sensor. The general category warns about hot print components and requires tool testing.

Pinout and visuals

No connector pinout is provided by the cited wiki pages. The machine page links a Desktop User Guide but this dossier does not use external documentation to fill gaps.
