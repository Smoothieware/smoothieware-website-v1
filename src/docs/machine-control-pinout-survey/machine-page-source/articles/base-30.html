Interface reading

Signal domains: Motion control or motor phases, limits/probe, spindle and safety where fitted. Controller family: SLB-EXT.

What is still missing

Verify the installed board and harness; a LongMill model name alone does not establish SLB-EXT presence.

The SLB-EXT connector list applies to SLB-EXT. Older LongMill MK2 open-source electronics and LongBoard details describe a different controller generation; the pinout cannot be borrowed for it.
