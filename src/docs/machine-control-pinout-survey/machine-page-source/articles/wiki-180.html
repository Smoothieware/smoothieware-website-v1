Current source review · 2026-09-28

The Appropedia catalogue identifies Inmachines, a 600 × 400 mm work area and a 40 W CO₂ laser. Those specifications occur in both V1 and V2. The official V1 README describes LPC1768/grbl-LPC; the V2 README describes Teensy 4.1/grblHAL.

The V2 sheet provides twelve printed terminal marks per X/Y driver, separate laser-PSU control and mains/tube-return marks, seven- and nine-terminal supply drawings, L/N/Earth power-entry nets, chiller lead marks 1 and 3 and tube electrode marks. The controller positions, splice entries, sensor/motor cable conductors and other unnumbered endpoints have explicit editorial identifiers. Extra blank driver squares and unidentified rectangles in the power-plug icon are not counted as proven contacts.

The V2 BOM identifies DM556T drivers, LRS-100-24 and RSP-500-48A supplies, MYJG50W laser supply, LJ12A3-4-Z/AY probes, PS-3150 window sensor and CW-3000 chiller. These are design component identities, not fitted-hardware proof. The two DC supply drawings retain their seven-/nine-terminal descriptions without assigning an installed model or validating the drawn netlist.

The HardwareX paper names Laser Controller PCB V1.7; the repository README links a shield path named V1-0. No connector schedule is imported across that unresolved revision boundary. The paper describes 24 V inductive probes, 3.3 V to 5 V laser signal conversion and an ATtiny startup gate delayed by 6 s. Original controller outputs must not be paralleled with SmoothieBox outputs, and the existing startup gate, window sensor and chiller circuit must not be bypassed.

The chiller schematic labels only 1 and 3. The BOM reports a three-pole connector and three cores used while also specifying a two-core cable; the separate chiller cable is two-core. Its third pole is therefore listed with number and function unresolved, never as pin 2 or NC. Cable shields remain separate from cores and connector pins. USB and external-accessory pin schedules remain unknown.

Potential STEP/DIR routes require an exact DM556T electrical contract, original-controller isolation, input topology, polarity, voltage, current, timing and return qualification. Sensor and laser candidates likewise lack the necessary interface and safe-startup evidence. This reference increment therefore selects zero function guesses and zero routes.
