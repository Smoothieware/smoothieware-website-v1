Documented evidence · unresolved wiring

Documented / version scope: Acorn start guide is an index/intro; Rev 3 specification manual and Rev 4 specification manual provide revision-scoped contact details. Rev 4 PDF p. 6 I/O map explicitly lists input 1–4 on H4 pins 5–2 and input 5–8 on H1 pins 5–2; outputs 1–8 are open collector on H10 pins 2–9; analog output 0–10 V is H8; H6 DB25 offers alternate 5 V logic for selected I/O. PDF p. 7 connection diagram locates H2/H3 step/dir/enable, H9 24 V power and Ethernet. Do not combine Rev 3 and Rev 4 contact positions without matching each manual. No named-machine harness here.
