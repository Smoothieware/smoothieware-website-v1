# FortheShiz's separate Shizuoka AN-S retrofit project

## Machine and project state

LinuxCNC Forum member FortheShiz states that they had just purchased a Shizuoka AN-S of the same type as the machine discussed by BtmInPa in the thread. The owner says this mill also had an Allen-Bradley control and the same servo-motor type, though its control had already been removed before purchase. In May 2021, the owner was seeking advice about which drives to use and asked whether BtmInPa had completed the other retrofit. No progress or completion for FortheShiz's own machine appears in the inspected thread.

This is a separate owner's physical mill, not a duplicate dossier for BtmInPa's machine; only the owner-reported shared model type and motor type are established.

## I/O and connector evidence

The post identifies a removed Allen-Bradley control and servo motors but no drive model, control interface, connector, contact, or wiring assignment. No pinout is established.
