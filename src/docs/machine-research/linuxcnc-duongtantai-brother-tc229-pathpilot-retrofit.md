# Duongtantai8624's Brother TC-229 (Taiwan clone frame) PathPilot retrofit

## Machine and retrofit

The owner identifies the machine as a Brother TC-229 with a Taiwan clone frame. In a LinuxCNC forum post dated 2021-07-28, the owner says they bought it cheaply, redid the electrical parts, and revived it. The same post says the machine still had some bugs but was doing useful work and improving the owner's business. The thread title describes the project as a PathPilot retrofit.

The owner reports a mixed axis drive arrangement: a servo on Z and step motors on X and Y. They added an encoder to the spindle motor for an index signal and state that the VFD has a built-in index function. The forum post links owner demonstration videos for a G-code test run and an ATC test run; the post's wording and linked demonstrations are evidence of reported test activity, not a complete commissioning record.

## Evidence and limits

The forum post includes an electrical-cabinet photograph and several machine photographs. The cabinet image shows installed control/electrical equipment, but the labels are not legible enough to identify component models or trace terminals. The machine photos show the work area and tool changer; they do not establish electrical connections.

The inspected post does not identify the stepper, servo, drive, VFD, encoder, or motion-controller models. It gives no terminal assignments, connector pin map, drive parameters, ATC input/output sequence, safety circuit, or complete wiring diagram. Do not treat this dossier as a wiring reference.
