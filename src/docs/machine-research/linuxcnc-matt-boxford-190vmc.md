# --Matt--'s Boxford 190VMC conversion project

## Machine and project state

LinuxCNC Forum member --Matt-- started a project to convert a Boxford 190VMC to LinuxCNC in June 2023. The owner had ordered a Mesa 7i96S and 7i84 and asked whether the machine's manual axis jog and spindle forward/reverse buttons could be used through Mesa inputs for a manual mode when the PC was disconnected. The inspected thread records this as a planned conversion and a design question, not a completed retrofit.

The exact Boxford 190VMC is separately listed in this repository's wiki research, but this dossier concerns a named owner's proposed retrofit; it makes no claim that the owner has the same historical London Hackspace machine. The forum does not connect these machines.

## I/O and connector evidence

The owner names panel functions—manual jog for each axis and spindle forward/reverse—and planned Mesa card models. No physical switch contact or machine connector mapping is supplied. Moderator replies discuss software-level feasibility rather than a wiring schedule.
