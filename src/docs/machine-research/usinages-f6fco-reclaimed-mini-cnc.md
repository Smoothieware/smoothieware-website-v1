# F6FCO's reclaimed-parts miniature CNC engraver

**Machine identity:** A compact CNC machine built by Usinages member F6FCO from MDF structure and reused photocopier components. The owner used it for engraving and PCB-related experiments.  
**Evidence state:** The owner reported engraving Morse-key paddles in June 2012, identified an earlier PCB-engraving problem, and later documented enclosure and spindle-light additions. The specific early PCB attempt was unsuccessful; later operation is not quantified.  
**Novelty check:** A repository text search on 2026-09-23 for “F6FCO”, the French thread title, and the thread identifier found no match outside this research directory.

## Build and motion system

The owner describes a 10 mm MDF frame, M8 lead screws, NEMA 23 stepper motors, and linear guides recovered from photocopiers. A PC power supply is also listed among the reused parts. The machine's original control approach included an Arduino, but the owner later says a purchased controller replaced it. The thread uses inconsistent four-axis/five-axis descriptions; this dossier therefore does not assign an exact axis/controller configuration beyond noting that the control electronics changed.

The spindle is itself a reuse project: F6FCO assembled it from Toshiba photocopier parts. After identifying eccentricity in an earlier spindle arrangement as a problem for PCB engraving, the owner reported installing an assembled replacement spindle on 28 June 2012 and using it to engrave Morse-key paddles. The thread does not provide a validated runout measurement or a repeatable PCB milling result.

## Operation and later changes

The thread records an early PCB engraving attempt that failed; the owner attributed the problem to spindle eccentricity. Later he reports that the replacement spindle was used to engrave paddles. In the final update dated 16 March 2013, he added an enclosure and spindle lighting. These posts support practical engraving use and subsequent additions, but not a completed PCB fabrication workflow or measured machine accuracy.

The thread does not give reliable travel dimensions, cutting speeds, material-specific parameters, or a long-term reliability history. No current operating status can be inferred from posts last updated in 2013.
