# mosoeng's Boxford bench-lathe retrofit project

## Machine and project state

LinuxCNC Forum member mosoeng reports attempting to retrofit a Boxford bench lathe with new servo drives and AC motors. The owner says the kit included PronetT-04A servo drives and a Mesa 7i97 Ethernet motion-control card. The post asks whether to configure the drives for analog speed or position control and whether motor encoders should be wired to Mesa. The inspected thread presents this as an active project and question; it does not specify a Boxford model or report a working machine.

Do not conflate this machine with Einar's separately discussed Boxford 250B or other Boxford models. The post itself asks whether the setup is for a Boxford 250 lathe, so exact model identity is uncertain.

## I/O and connector evidence

The owner describes separate motor-power and encoder leads terminating in plugs that connect to the servo drives, but gives no connector family, contact numbers, electrical levels, or verified encoder route. Questions about the 7i97 and drive mode remain unanswered in the inspected page. No machine pinout is established.
