# LulzBot TAZ 3

Research status: wiki-sourced model dossier; SoMakeIt lists one SMI TAZ 5 instance as this model. Captured 2026-09-23.

## Wiki-recorded machine

SoMakeIt identifies the SMI TAZ 5 as a LulzBot TAZ 3. The wiki lists a 280 × 280 × 250 mm print volume, PEI bed, 0.5 mm nozzle (explicitly marked for confirmation), and PLA/ABS. The unit has no OctoPrint address listed; file transfer is via SD card. Slicing software is listed as LulzBot Cura 21.08, Slic3r, or PrusaSlicer. The page labels status “functional,” also marked for confirmation.

## Use and limits

Use the documented SD-card path and treat the nozzle size and status as unverified wiki entries requiring a local induction/check. The page does not give a model-specific start-up or maintenance sequence.
