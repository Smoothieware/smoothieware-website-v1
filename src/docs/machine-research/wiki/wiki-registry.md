## Access limits and exclusions

Not counted: Nottinghack, hackerspaces.org, TechInc, i3Detroit and Protospace challenged automated access; LinuxCNC access failed; FAU FabLab required login. A cached page or inaccessible guessed host did not establish a counted wiki. No challenge bypass was attempted. Ordinary vendor pages, forums, GitHub README files, and external documentation were not used as supporting sources.

London robots disallows `/w/` except its loader and requests a 30-second crawl delay, so its `/w/images/` files were not fetched. Happylab article `/w/` and image paths were used, avoiding blocked query/index paths. Evil Mad Scientist requests a 10-second delay. Munich allows ordinary article/media paths but blocks Special pages. Sorbonne, HSBNE and profs.ch returned no robots file (404). Dallas robots access returned 403; no direct Dallas media download was pursued.
