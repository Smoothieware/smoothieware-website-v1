# CNC Automation M3X mill

## Identity

Artisans Asylum calls the machine “M3X CNC Milling Machine,” maker CNC Automation, model M3X, serial 041721. The wiki notes that the nameplate says “Accu II,” while the machine's functional name is M3X; preserve both identifiers.

The owner page, retrieved for this review on 2026-09-27, describes three-axis table motion, servos and a CNC Automation control system driven by a DOS computer in the rear power box. This is source-reported architecture, not a confirmed controller-board model, fitted revision or STEP/DIR input contract. The owner page itself displays a 2025-01-21 last-updated date. [A1]

## Operation

The wiki describes G-code generated by CAD/CAM, optional simulation, then machining a vise-held metal workpiece. The spindle is raised/lowered and tooling changed manually. Startup involves checking the E-stop, energizing the power box, booting the DOS computer and loading a program from USB. The listed shutdown options include the front E-stop or saving/quitting before powering down. Training is required; automatic movement can start unexpectedly.

This paragraph records the owner's operating description, not a retrofit procedure or a safety-circuit schematic. Manual spindle raising/lowering and tool changing do not establish spindle-control connector functions. [A1]
