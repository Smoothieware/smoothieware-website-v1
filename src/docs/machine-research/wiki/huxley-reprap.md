# RepRap Huxley (community design)

## Identity

The RepRap Huxley wiki describes a compact community printer design based on Mini-Mendel. It is separate from the documented RepRapPro Huxley kit implementation.

## Wiki evidence

- [RepRap Huxley](https://www.reprap.org/wiki/Huxley): machine lineage, component-size choices, electronics standard and build-guide links.
- [RepRapPro Huxley](https://www.reprap.org/wiki/RepRapPro_Huxley): separate manufacturer implementation, cited only to distinguish the variant.

## Machine and operation

The wiki describes Huxley as a smaller, one-material alternative to Mendel using M6 threaded rod, M3 fasteners, NEMA 14 motion steppers and a Bowden extruder. It says electronics may meet RepRap Interface Standard 1; it does not specify one board. Build and commissioning documentation is linked from the wiki.

## Pinout

No universal pinout is specified. RepRap Interface Standard compliance is a compatibility reference, not proof that all Huxley builds use the same connector orientation or wiring.

## Visuals and limits

The article links build photos and parts documentation but the surfaced text contains no verified contact-level wiring diagram. The project includes variants; use matching version-specific instructions.
