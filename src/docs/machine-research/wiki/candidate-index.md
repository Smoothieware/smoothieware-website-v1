# Wiki machine candidate index

This index covers every per-machine Markdown file in this folder. A dossier is a sourced research record, **not by itself proof of novelty** against every pre-existing page, alias, or concurrent research file. Use the `Evidence depth` column to distinguish detailed wiki pages from Appropedia catalogue-only entries and historical machines. Pinout and visual gaps remain in individual dossiers. The current identity screen and its limitations are recorded in [`novelty-audit.md`](novelty-audit.md).

**Dossier files:** 125. **Appropedia catalogue-only dossiers:** 33. **Other wiki-backed dossiers:** 92.

## Repository overlap check

A normalized-title text scan compared these dossier identities with 421 current Markdown/HTML files elsewhere under `docs/` and `src/docs/`. It found four existing text matches: Laser4DIY and PrintNC appear in the parallel forum-research README, RepRap Wallace and Huxley are listed in the 3D-printing landing page, and Ultimaker 2 appears as donor electronics in a forum build dossier. Review against the atlas's 107 profile labels found Tormach 8L, MPCNC, OpenBuilds ACRO, and Shapeoko 3 XXL overlaps. The MK4S is conservatively grouped with the existing MK4 family. These ten identities are excluded, leaving 115 candidates with no known exact/family overlap in this screen. The 421-file text scan can still miss aliases, family names, title variants, or names described without the model string. The count includes 29 candidates supported only by Appropedia catalogue rows; it is a candidate count, not proof of 100 richly documented machines. See [`novelty-audit.md`](novelty-audit.md) for the full exclusions and coverage limits.
