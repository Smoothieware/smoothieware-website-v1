# Schaublin 102-VM

Research capture: 2026-09-28. FabLab Winti directory links to pinned Drehbank page revision 349. Status: wiki-grounded manual-lathe profile.

## Identity, use and deduplication

FabLab Winti manual lathe. The machine directory labels the linked Drehbank page “Schaublin 102-VM”; the image also shows the model on the bed. This is distinct from the atlas Tormach/Sherline/Taig lathes. It is manual maker machinery, not a newly identified CNC retrofit.

## Wiki-supported machine facts

Wiki specifies 16 × 16 mm tools and requires mechanical training and induction. It reports a tailstock center-height alignment problem at this installation; that is a local maintenance condition, not a universal 102-VM characteristic. [FabLab Winti community machine page, pinned revision 349](https://www.profs.ch/flwiki/index.php?title=Drehbank&oldid=349).

## Control, setup and use

The source advises finishing precision bores by boring rather than relying on drilling while the stated alignment problem remains. CNC homing, G-code and motion-controller setup are not applicable to the documented manual configuration. Motor starter ratings and terminals remain unknown.
