# DIYDER's RS-CNC32 router

**Machine identity:** An RS-CNC32 machine built and used by Lesimprimantes3D forum member DIYDER. This dossier covers that owner's machine, not every RS-CNC32 build.  
**Evidence state:** In a 15 November 2023 post, DIYDER says the machine is used with GRBL and can start G-code from an SD card without a connected PC. The post establishes owner-reported use, but no specific finished cut, measured accuracy, or long-term operating record was recovered.  
**Novelty check:** A repository text search on 2026-09-23 for “DIYDER”, “RS-CNC32”, and the thread title found no matching machine dossier outside this research directory. The model family is named in the forum inventory, but no pre-existing individual-machine dossier was found.

## Construction and configuration

DIYDER says the machine was built using largely reclaimed mechanical parts and uses remote motor drivers. The owner names a Makita RT0700C trim router and GRBL control, and says G-code can be read from an SD card without leaving a PC attached. FreeCAD and Fusion 360 are listed as design/file-generation tools.

The inspected post does not give this particular machine's travel, exact RS-CNC32 revision, controller-board model, motor/driver part numbers, spindle speed range, accuracy, or material capabilities. It also does not provide a complete build bill of materials or distinguish every reused component. Those unknowns should not be filled from other users' RS-CNC32 machines.

## Reported use

The owner writes that they built and use the machine, and describes an offline workflow in which a G-code file is started from SD storage. No specific cut or engraved part is identified in the recovered post. Thus this dossier records owner-reported operation but does not claim a verified first cut, successful material test, or measured performance.

The forum profile mentions a laser, but the substantive machine post does not establish that a laser was fitted or operated on this RS-CNC32. Laser capability is therefore excluded from the confirmed configuration.

## Pinout and operation limits

The post does not give the controller board revision, stepper-driver wiring, connector pin map, spindle-control terminals, endstop/probe assignments, or emergency-stop circuit. SD-card operation and the GRBL label do not establish those electrical details. This dossier is not a wiring guide.
