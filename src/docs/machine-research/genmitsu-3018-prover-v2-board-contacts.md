# Genmitsu 3018-PROVer V2 board-view contacts

Checked 2026-09-26 against the manufacturer's [3018-PROVer V2 User Manual v1.0 (2022)](https://genmitsu.s3.us-east-1.amazonaws.com/101-60-3018PV2/3018-PROVer_V2_User_Manual_%E3%80%90EN%2BDE%2BJP_V1.0_20220906_1.pdf) and SainSmart's hosted [hands-on review](https://www.sainsmart.com/blogs/news/review-of-genmitsu-3018-prover-v2-cnc-router). The 104-page trilingual manual was captured as `/tmp/atlas-genmitsu-3018-prover-v2-manual.pdf`, SHA-256 `cc2f96a8db3e82f0cf6eec8db06297c119af398d9d6c2109928a165308bfb0b3`. Its printed English pp. 15–20 correspond to PDF pp. 17–22. The board overview at PDF p. 21 was rendered at `/tmp/atlas-genmitsu-3018-prover-v2-board-detail-021.png`. The hosted review's board photograph, `/tmp/atlas-genmitsu-3018-prover-v2-blog-board.png`, visibly labels the photographed example GC3D3-V4.3; the reviewed example does not prove that every V2 has that exact subrevision.

The manual describes a 32-bit/TB67S109 controller, a 24 V supply, three axes, a 775 DC spindle, a Z-probe, an E-stop, and an offline controller. Its wiring section explicitly describes a **four-wire Y motor cable** and **three-wire Y limit cable**; the board drawing shows equivalent X and Z motor sockets and two limit sockets per axis. The hosted review says the photographed machine's six limit board sockets have **only three occupied**, with each axis's two switches wired in parallel. Neither source identifies which of each socket pair is occupied for all production units. This differs from the first-generation GC3D3 manual's six separate limit-board cables; never transfer that V1 cable topology to V2.

## Selected board and machine positions

| Interface | Count | Source scope and limit |
| --- | ---: | --- |
| X, Y, Z motor sockets | 4 each | Manual board drawing (printed p. 19) shows four visible contacts per socket; printed p. 16 calls Y cable four-wire. These are **former-controller winding outputs after the on-board TB67S109 drivers**, not STEP/DIR inputs. Board-view ordinal, motor coil mapping and fitted cable continuity are unverified. |
| X/Y/Z limit socket A and B | 3 each, six sockets | The manual board drawing shows two sockets per axis; its Y wiring instruction says three-wire cable. The hosted review says only one per axis was occupied in its machine, with two switches in parallel on that axis. A/B are drawing-order aliases, not maker pin names, min/max assignments, or evidence that both sockets are wired. Pin signal, supply and return order is unverified. |
| Spindle motor red/black leads | 2 | Manual printed p. 15 explicitly identifies red positive and black negative at the motor. These are motor-power conductors, not a SmoothieBox logic output or qualified switched-load path. |
| Z-probe socket | 3 | The hosted V2 review specifically describes a three-pin, illuminated probe; the manual labels the board PROBE. Individual signal/power/return cavities are unverified. Do not reuse the first-generation two-position probe assignment. |
| E-stop socket | 2 | The hosted board review calls this two-pin. The manual shows a machine emergency-stop switch, but gives no safety-rated circuit, NC/NO state, or contact order. |
| Offline controller | 10 | Manual board drawing shows a 2×5 accessory header; hosted review calls it ten-pin. The signals and mating-face numbering are unverified. This is a former-controller accessory. |
| Optional laser socket | 3 | The hosted review calls the V2 output a three-pin 12 V laser/PWM connector; manual labels a LASER module interface. No installed laser or module electrical contract is proved. |
| Optional air-assist socket | 2 | The hosted review calls it a two-pin air-assist control socket and explicitly treats actual use as uncertain. Manual board drawing labels AIR. No pump rating, switching stage or fitted cable is proved. |

The separate MPG/handwheel port, USB interface, power jack and rocker switch appear in the source drawing but have no trustworthy individual pin function map here and are not treated as SmoothieBox peripheral signals. All 52 selected positions are **REFERENCE ONLY / OPEN**. A replacement motor driver, coil continuity, limit switch wiring, spindle power stage, emergency-stop circuit and final SmoothieBox electrical qualification require fitted hardware evidence before a conductor is drawn. No direct route or dotted guess is selected.
