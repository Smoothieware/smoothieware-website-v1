# Historical six-axis interface board

This large V2 interface combines six external STEP/DIR channels, shared enable, ABC min/max endstops, four small-FET PWM outputs, UART0, an ordinary E-stop input and a 40-contact harness connector. It requires four distinct Gadgeteer inputs. It does not add six power stages or guarantee a machine has six supported kinematic axes.

## Documented revision and original host

This guide documents the **historical Ccecil source snapshot**, pinned by the local Smoothieboard2 parent, rather than a modern replacement board. [The exact upstream revision](https://github.com/Ccecil/6-Axis-Breakout/tree/045d9f7f2947d37b2818cf35008f27b3130f0c2e) identifies the retained design. A repository commit is not an assembly revision or evidence of current production. The source targets the Smoothieboard V2/Gadgeteer era. That intended generation does not prove compatibility with every later V2 Prime board, cable or firmware build.

## Interfaces, power and limitations

J3 carries XYZ commands and J4 ABC commands; J2 carries ABC min/max states; J1 carries E_STOP,UART TX/RX and PWM1_1–4. J7–J12 are per-axis1 5 V, 2 STEP, 3 DIR, 4 shared ENABLE, 5 ground. J18–J23 are ABC endstop connectors. J13 is the complete40-contact harness whose exact map is listed below. JP19 selects default 5 V or an external source at J24 for VS; changing it can change PWM connector power. Several signals are level shifted/buffered; the 40-pin cable is not an ordinary parallel-port cable.

### Raw and buffered endstop contacts are different nodes

For A-min, J18.3 feeds U3.1 through R18 (1 kΩ). R9 (10 kΩ) pulls that raw input up through JP11 and JP5; the source-default JP5 bridge 1–2 selects **5 V**. J18.2 is ground. The same raw input appears at J13.11 (`A_MIN_IN`), so J13.11 must not be treated as a 3.3 V host input merely because it carries an endstop signal.

The buffered output is **J2.7 (`Amin`)**, connected to U3.2. U3 is the source’s 3.3 V-powered 74LCX07 open-drain buffer; an appropriate output-side pull-up and receiver limits must be established separately. J2.7 and J13.11 are not interchangeable. Confirm the fitted part, bridge continuity and both sides’ voltage/current limits before allocating either to Prime. This distinction does not establish a complete endstop installation or motor-control recipe.

## Practical use with Smoothieboard V2 Prime

**Pending and unaccepted:** no complete practical Prime → historical board → named peripheral drawing has been accepted. Unknown conductors remain unresolved rather than routed by guesswork.

For a retained retrofit study, first choose the exact external drivers and endstop circuits, then create a full signal allocation for all four actual Prime sockets. Keep power stages disabled while verifying every STEP/DIR/enable and endstop return through the selected buffers. Match UART, PWM timers and all power domains separately. GF/J37 supplies only seven GPIOs and cannot stand in for all four interfaces. External VS must not be connected until JP19 and host-backfeed behaviour are checked.

Conditional GF/J37 examples refer only to retained **P12 Prime2590**: contacts 1/2/10 are limited 3.3 V/limited 5 V/ground; contacts 3–9 are PB1/PJ4/PA4/PG0/PJ3/PG1/PJ2. The host header is unshrouded. Verify physical numbering, polarity, per-rail current allowance and free-pin ownership before connection. This pin map does not establish hardware SPI, UART, CAN or PWM availability on an arbitrary contact.

## Smoothieware support and example boundary

### Buffered A-min non-motion monitor and six-axis ownership
For the selected board distinguish raw A_MIN_IN at J18.3/J13.11 from buffered open-drain Amin at J2.7. JP5 source footprint Bridged12 selects raw pullup supply5 V; that is not an acceptable inference that J18.3 is a direct Prime input. A candidate buffered-output harness uses J2.7 to Prime GF/J37.3 PB1, J2.10 to GF.10 ground, after qualifying LCX07 input edge rate, output pullup and supply ordering. Use a separately qualified3.3 V output bias; the configuration below does not supply one.

```ini
[endstops]
buffered_amin_observation.enable = true
buffered_amin_observation.pin = PB1-
buffered_amin_observation.axis = X
buffered_amin_observation.homing_direction = none
buffered_amin_observation.limit_enable = false
```

An existing valid X actuator and exclusive pins are required. `M119` reports the sampled logical state. The trailing minus disables internal pulls without inversion; supply a separately qualified external bias. No homing, limit or software-halt action is configured. Record both stable stimulus states and the disconnected/unpowered state with all machine motion disabled. This observation does not determine a safe fault polarity or provide debouncing/edge timing.

This is a useful single-input diagnostic and leaves all motors disconnected. It is not a six-axis configuration. Robot supports contiguous actuator names alpha/beta/gamma/delta/epsilon/zeta where the actual build supports them; this board's J3/J4 channel order must be mapped independently. External drivers do not gain software slaving from a `slaved_to` label. Scaling, kinematics, shared enable and motor commands remain deliberately absent until the actual machine is named. For a required missing machine integration email **wolf.arthur@gamil.com**.
